# ことば / Kotoba

**文章を選んで⌘J。Mac上で動く日英翻訳アプリです。**

Apple Intelligenceのオンデバイスモデル、またはOllamaのローカルモデルで翻訳します。原文と訳文を専用ウィンドウに表示し、外部APIの契約やAPIキーは不要です。

- 日本語 → 英語、英語 → 日本語に対応。翻訳方向は自動判定・手動指定できます。
- 他アプリの選択文章、手入力、貼り付け、クリップボードから翻訳できます。
- 訳文を生成途中から表示し、中断・コピー・文字サイズの変更ができます。
- メニューバーに常駐。履歴は必要なときだけ、このMacに保存します。

## 必要な環境

| 項目 | 必要なもの |
| --- | --- |
| Mac | Apple Silicon搭載、macOS 26以降 |
| ビルド環境 | Swift 6.2系以降、macOS 26対応SDK。Xcode 26.3 / Swift 6.2.4で確認済み |
| 標準の翻訳エンジン | Apple Intelligenceを有効にし、オンデバイスモデルの準備を完了 |
| 任意の翻訳エンジン | 別途導入したOllamaとローカルモデル |

ソースコードからビルドして利用します。公証済みの配布アプリやモデルの重みは含みません。初回の開発環境・モデルのセットアップにはネット接続が必要です。

## はじめる

### 1. ビルドして起動する

```sh
git clone https://github.com/Kipeo22/translation-app4local.git
cd translation-app4local
zsh scripts/build-app.sh
open dist/Kotoba.app
```

`dist/Kotoba.app`を生成し、アドホック署名を付けます。Developer ID証明書は不要です。開発環境が見つからない場合は[トラブルシューティング](docs/troubleshooting.md#ビルド環境が見つからない場合)を参照してください。

### 2. 文章を翻訳する

原文欄に入力・貼り付けし、**「翻訳する」または⌘Return**を押します。初期エンジンはApple Intelligenceです。Ollamaを使う場合は、設定でエンジンと導入済みのモデル名を選んでください。初期モデル名は`translategemma:12b`です。

### 3. 他アプリの選択文章を翻訳する

1. システム設定 → プライバシーとセキュリティ → アクセシビリティで「ことば」（またはKotoba）を許可します。
2. 元のアプリで文章を選び、**⌘J**を押します。
3. 翻訳ウィンドウに原文と訳文を表示します。

手入力・貼り付け・macOSの「サービス」→「ことばで翻訳」は、アクセシビリティの許可なしでも使えます。選択取得への対応はアプリによって異なります。取得できない場合は[対処方法](docs/troubleshooting.md)を参照してください。

## 主な操作

| 操作 | 方法 |
| --- | --- |
| 選択文章を翻訳 | ⌘J。競合する場合は設定でControl+Option+T / R / Yに変更 |
| 入力した文章を翻訳 | 「翻訳する」または⌘Return |
| 完了した訳文をコピー | 「コピー」または⇧⌘C |
| 文字サイズを変更 | 訳文欄の右上にある文字サイズボタン（16〜32pt） |
| ウィンドウを閉じる | メニューバーに常駐し、次の呼び出しを待ちます |
| アプリを終了 | メニューバーの「終了」または⌘Q |

ウィンドウと原文・訳文の仕切りはサイズを変更できます。下部の「最初の文字」「完了」は、その翻訳にかかった秒数です。

## データとプライバシー

- **翻訳処理**：Apple Intelligenceはオンデバイス推論を使います。Ollamaの接続先は`127.0.0.1:11434`です。Ollama側のモデル・実行設定・更新は別途管理してください。
- **履歴**：初期オフ。有効にすると原文・訳文などを`~/Library/Application Support/Kotoba/history.json`へ最大500件保存します。アプリ独自の暗号化は行いません。
- **履歴の削除**：保存をオフにしても既存データは残ります。設定の「保存した履歴をすべて削除」で削除できます。
- **取得と通信**：クリップボードの常時監視は行いません。任意の自動コピー補助は初期オフです。アプリに解析・広告・クラッシュ報告の送信処理はありません。

## 現在の制約

- アドホック署名のため、再ビルド後にアクセシビリティの再許可が必要になる場合があります。
- 選択取得、コピー補助、複数デスクトップ・フルスクリーン上での呼び出しなどは、実機での確認範囲が限られます。
- OCR、長文分割、ログイン時自動起動、クラウドモデルへの接続は未実装です。
- CIはビルドと処理ロジックを確認します。翻訳品質やOS権限の実機確認は含みません。

詳しい実装・検証記録は[実装メモ](docs/implementation.md)にあります。[初期仕様案](docs/specification.md)には未実装の提案も含まれます。

## 開発・貢献

`main`は公開版、`dev`は開発の統合先です。機能追加や修正は`dev`から作業ブランチを作り、`dev`へPRを出します。

```sh
zsh scripts/check.sh
```

テスト・リリースビルド・アプリの署名検証をまとめて実行します。外部Swiftパッケージは使っていません。読み始めるファイル、不具合報告、CI、リリース方針は[開発・貢献ガイド](CONTRIBUTING.md)を参照してください。

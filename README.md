# ことば / Kotoba

選択した文章を日英翻訳する、個人用のMacネイティブアプリです。小さな結果ポップアップを使わず、サイズ変更できる専用ウィンドウに原文と訳文を表示します。

## 起動

1. `dist/Kotoba.app` を開きます。
2. 初期エンジンはApple Intelligenceのオンデバイスモデルです。Apple Intelligenceが有効なmacOS 26以降のMacが必要です。
3. 手入力・貼り付けの場合は、原文を入力し「翻訳する」またはCommand+Returnを押します。
4. 他アプリの選択文章を取得する場合は、システム設定 → プライバシーとセキュリティ → アクセシビリティで「ことば」（またはKotoba）を許可します。
5. 元のアプリで文章を選び、Command+Jを押します。

初期キーはCommand+Jです。以前のControl+Option+Tから変更しました。同じキーが他で登録されている場合は、そちらを解除するか、「ことば」の設定でControl+Option+T／R／Yに変更できます。登録失敗は設定画面にも表示します。

## 表示と操作

- ウィンドウは初期900×730pt、サイズ変更可能。原文・訳文の間の仕切りも動かせます。
- 訳文の文字サイズは右上の大小の文字ボタンで16〜32ptに調整できます。
- 訳文を生成途中から表示します。途中結果・中断・完了を区別します。
- 完了後に「コピー」またはShift+Command+Cで訳文をコピーできます。
- 下部の「最初の文字」「完了」はそのリクエストの実測秒数です。
- ウィンドウを閉じてもメニューバーに常駐します。終了はメニューバーまたはCommand+Qから行います。
- 履歴保存は初期オフ。オンにした場合、直近500件をこのMacに保存します。

## 選択文章を取得できない場合

Accessibility APIに対応しないアプリでは、設定の「選択を取得できないとき、自動コピーで補助する」をオンにして試せます。操作は選択→キーのままです。アプリが内部でコピーし、復元可能なクリップボード内容を戻します。保護された入力欄は取得しません。任意のアプリでの取得は保証しません。

自動コピー補助は初期オフです。復元できない形式・大きなデータがクリップボードにある場合は補助を行いません。クリップボードの常時監視はしません。

また、アプリを開いた後にOSへ登録される「サービス」→「ことばで翻訳」から、選択文章を渡す経路もあります。サービスの表示にはOSの登録更新が必要な場合があります。アクセシビリティの許可がなくてもサービス経由と手入力は使えます。

## 翻訳エンジン

- **Apple Intelligence**: Foundation Modelsのオンデバイス推論を直接使います。ショートカットを起動せず、文章ごとに新しいセッションで訳します。起動時に利用可能ならプリウォームします。
- **Ollama（任意）**: 導入済みのローカルモデルを指定できます。`127.0.0.1:11434` にのみ接続します。初期モデル名は`translategemma:12b`で、アプリはOllamaやモデルを勝手にインストールしません。

Appleのショートカットで選べるクラウド／Cloud Proと同じモデルを、現在のアプリで直接使う機能はありません。AppleのPrivate Cloud Computeを独自アプリから使う場合の追加条件と、手元のSDKの対応状況を確認し、初版はオンデバイスで実装しています。外部APIの契約やAPIキーは不要です。

## 開発

外部パッケージは使っていません。Swift 6.2系コンパイラ、macOS 26対応SDKでビルド確認済み。Swiftの言語モードは5です。

```sh
zsh scripts/build-app.sh
swift test --cache-path .build/package-cache
```

ビルドすると`dist/Kotoba.app`を作り、個人用のアドホック署名を付けます。公証済みの配布アプリではありません。同じ保存場所・バンドルIDで使うことを推奨します。再ビルド後にmacOSがアクセシビリティの再許可を求める場合があります。

- リリースビルド成功。

- Apple Intelligenceでテスト用英文の実翻訳と、アプリ自身の画面画像を確認。
- 同じ短文を2回確認し、1回目は最初の文字約1.3秒・完了約1.4秒、2回目は最初の文字約0.9秒・完了約0.9秒を計測。一般的な速度の保証や、元のショートカット・Naniとの比較結果ではありません。
